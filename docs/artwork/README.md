# Show artwork

This directory holds the cover art that the main `README.md` and the new
`WeeklyCup-Episode-Generator` repo reference.

Drop the two cover image files here with these exact filenames so the README
renders correctly on GitHub and on podcast directories:

| File | Aspect | Use |
|------|--------|-----|
| `cover-1x1.png` | 1:1 (square, 1080×1080 or higher) | Apple Podcasts, Spotify, RSS `<itunes:image>`, social avatars |
| `cover-16x9.png` | 16:9 (landscape, 1920×1080 or higher) | YouTube, README banner, social card |

Quickest path to add them on GitHub:

1. Open <https://github.com/pennydoesdev/themorningcup-episode-generator/tree/claude/weekly-rewind-generator-tpNXg/docs/artwork>
2. **Add file → Upload files**
3. Drag both PNGs in, name them `cover-1x1.png` and `cover-16x9.png`
4. Commit directly to the `claude/weekly-rewind-generator-tpNXg` branch
